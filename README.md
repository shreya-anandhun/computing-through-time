# Computing Through Time

An online museum exhibit about the history of computers, from ENIAC in 1945 to generative AI in 2022. Built for curious teenagers who have never wondered where computers came from.

**Live site:** https://shreya-anandhun.github.io/computing-through-time/

## What's inside

| Page | What it does |
|---|---|
| Home | Animated journey through six exhibits, and a ticker of every milestone |
| Timeline | Ten milestones you can open, filter by era, search, or pick at random |
| People | Profiles of Alan Turing and Grace Hopper |
| Quiz & About | Five questions with instant feedback and confetti, plus credits and sources |

Other features:

- Dark and light mode that remembers your choice
- Definitions for unusual words: hover on a laptop, tap on a phone
- Scroll animations built with the Intersection Observer API
- Works on phones, tablets and desktops
- Keyboard friendly, and respects "reduce motion" settings

## Built with

Plain HTML, CSS and JavaScript. No frameworks, no libraries. Every illustration is a hand-made SVG.

## Run it locally

Download or clone the repo and open `index.html` in a browser. Nothing to install.

```
git clone https://github.com/shreya-anandhun/computing-through-time.git
```

## Project structure

```
index.html       Home
timeline.html    Timeline
people.html      People
quiz.html        Quiz and About
css/style.css    All styles
js/data.js       Milestones, glossary and quiz questions
js/main.js       Theme, navigation, scroll effects, tooltips
js/timeline.js   Timeline interactions
js/quiz.js       Quiz logic and confetti
js/sparkles.js   Background sparkles
images/          SVG illustrations
```
